## 前台首页响应式

- [ ] 1440px：首页 Hero 和 ProfileCard 正常并排，右侧不裁切，无横向滚动条。
- [ ] 1280px：ProfileCard 不被裁切，SiteDashboard 统计卡片不溢出，顶部导航不溢出。
- [ ] 1024px：首页 Hero 和 ProfileCard 自动变为单列或合理压缩，fixed 控件不遮挡内容，无横向滚动条。
- [ ] 390px：首页可读可操作，导航可操作，统计卡片换行，右侧/底部浮动控件不挡正文和按钮。
- [ ] 1440px、1280px、1024px、390px 下主内容左右边距基本一致，页面不能视觉上向右顶出。
- [ ] 顶部导航、Hero/ProfileCard、SiteDashboard、LatestPosts 使用同一主内容宽度，不出现导航居中但首页右贴边。
- [ ] 右侧主题/背景/弹幕按钮不遮挡 ProfileCard 或主要内容。
- [ ] FloatingPlayer 不遮挡文章内容、评论区和主要按钮。
- [ ] 页面整体无横向滚动条，图片和卡片最大宽度不超过 viewport。
- [ ] 即使没有横向滚动条，也不能出现 ProfileCard、头像、昵称、统计、社交按钮或 SiteDashboard 最右侧卡片被裁切；出现裁切即为不通过。
- [ ] 首页“最新文章”不是横向滚动轨道；4 篇文章在当前主容器宽度下应换到第二行第一列，而不是继续排成第一行第四列。
- [ ] 文章数量从 1、2、3、4、5 变化时，首页主容器宽度和左右边距不跳变。
