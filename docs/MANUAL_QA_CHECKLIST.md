# Manual QA Checklist

本清单用于浏览器人工回归。除非全部相关项通过，否则不要把 `docs/XINGHUI_PARITY_MATRIX.md` 中对应模块标记为 `已完成`。

## 前台文章详情

- [ ] `/posts/srblogs-p0-20260502130609` 可打开。
- [ ] `/posts/vue-fastapi-blog` 可打开。
- [ ] 标题、日期、标签、摘要正确。
- [ ] Markdown 正文正常。
- [ ] 代码块高亮正常。
- [ ] TOC 显示并可点击滚动。
- [ ] 图片加载失败有兜底。
- [ ] 分享按钮点击不报错。
- [ ] 不存在 slug 显示 404/错误状态，不白屏。
- [ ] 390px 移动端可读。

## 后台 Markdown 编辑器

- [ ] 点击“插入预览测试样例”后，右侧预览是真实 Markdown 渲染，不是纯文本。
- [ ] 一级标题明显大于二级标题，二级标题明显大于三级标题。
- [ ] 无序列表显示项目符号。
- [ ] 有序列表显示 1、2、3 编号。
- [ ] blockquote 有引用样式。
- [ ] inline code 有等宽字体和背景。
- [ ] fenced code block 有等宽字体、背景和横向滚动。
- [ ] table 显示为表格，窄屏不横向撑破页面。
- [ ] link 有链接样式。
- [ ] image 最大宽度不超过预览区。
- [ ] 预览仍经过 DOMPurify 清洗。

## 前台评论区

- [ ] 评论列表加载状态可见。
- [ ] 空状态可见。
- [ ] 错误状态可见。
- [ ] 昵称不能为空。
- [ ] 评论内容不能为空。
- [ ] 邮箱可为空。
- [ ] 非法邮箱有提示。
- [ ] 提交成功后列表无刷新更新。
- [ ] 长评论换行正常。
- [ ] XSS 内容不被危险渲染。

## 后台评论管理

- [ ] `/admin/comments` 可进入。
- [ ] 重启后端后，`http://127.0.0.1:8000/docs` 中能看到 `GET /api/admin/comments/index`。
- [ ] 登录后直接请求 `GET /api/admin/comments/index` 返回 200，不再是 404。
- [ ] 页面打开后不需要手动输入 slug。
- [ ] 默认显示有评论的内容索引。
- [ ] 索引项显示标题、resource、slug、评论数和最近更新时间。
- [ ] 点击索引项后自动加载对应评论。
- [ ] 当前选中项有 active 状态。
- [ ] 删除评论成功。
- [ ] 删除不存在评论显示错误。
- [ ] 删除后前台评论区同步变化。
- [ ] 删除后评论列表数量减少，索引 count 同步刷新。
- [ ] 删除前 `backend/data/comments/.backups` 生成备份。
- [ ] 手动 resource/slug 加载只在“高级加载”折叠区中出现，不作为主流程。

## 后台写作

- [ ] 后台新建非草稿文章。
- [ ] 文件写入 `backend/data/posts`。
- [ ] 前台文章列表出现。
- [ ] 前台文章详情可打开。
- [ ] 非法 slug 的 UI 错误提示可见。
- [ ] 空标题的 UI 错误提示可见。
- [ ] 重复 slug 的 UI 错误提示可见。
- [ ] 页面明确提示当前保存为直接持久化，`pendingOperations` 尚未实现。
