# SRBlogs 真实使用手册

## 2026-05-03 使用补充：GitHub 评论、全局音乐与相册组

- 评论：新评论需要 GitHub 登录。若后端未配置 GitHub OAuth Client ID/Secret，前台文章详情会显示“GitHub 登录未配置”；配置后点击“使用 GitHub 登录后评论”完成授权再发表评论。旧本地评论仍可展示。
- 后台设置中心的评论设置只保留 GitHub 登录评论所需配置、评论开关和最大长度；旧的本地匿名评论、邮箱必填、邮箱显示配置不再作为主流程。
- 音乐：首页播放器和 `/music` 页面共享同一播放状态，切换页面不会自动停止。后台音乐管理可上传音频/视频 URL，也可上传 `.lrc` 或 `.txt` 歌词文件并回填 `lyricUrl`。
- 照片墙：后台照片墙以“相册”为主流程，每组最多 50 张照片；封面可手动填写，留空时默认使用第一张。前台默认显示相册封面，点击后查看组内照片。
- 相册编辑时可以预览组内照片、继续追加照片、删除单张照片、拖动或用上移/下移调整顺序，并可将任意照片设为封面。
- Markdown 编辑器：桌面端可拖动中间分隔条调整编辑/预览比例，移动端用编辑/预览切换。字体颜色通过工具栏“色”按钮打开自定义颜色面板，不使用浏览器原生弹窗。
- 点击音效：在后台设置中心的“主题与背景”中可配置是否启用、音量和自定义音效 URL；前台只在按钮、链接、导航、表单控件等交互元素点击时播放。
- 后台导航：设置中心子项已并入左侧主导航“系统 > 设置中心”，不再通过页面主体里的独立二级导航切换。

## 2026-05-03 使用补充：弹窗编辑、上传限制与点击音效

- 友链、项目、音乐、照片的新增和编辑现在通过居中弹窗完成；列表页默认不常驻显示表单。保存成功后弹窗关闭并刷新列表，保存失败会留在弹窗内显示错误。
- 写作页默认显示“打开 Markdown 编辑器”入口。点击后进入近全屏弹窗，桌面端左侧编辑、右侧预览，移动端可切换编辑/预览。
- Markdown 工具栏可收起，支持加粗、斜体、列表、引用、代码、表格、链接、图片和字体颜色。字体颜色使用安全的 `#RRGGBB` 格式插入，并继续经过 DOMPurify 清洗。
- 本地上传按类型分档：图片 10 MB，音频 100 MB，视频 200 MB。超出限制或类型不支持时，后台会显示明确错误。
- 前台“点击音”开关控制交互点击音效；仅按钮、链接、表单等交互元素点击会播放，空白区域不会播放。
- 首页右下角悬浮播放器已移除，音乐入口集中在首页主播放器和 `/music` 页面。

## 2026-05-03 使用补充：后台导航、主题配置与本地资源上传

- 后台左侧导航已改为父子目录结构：总览、内容、互动、媒体、系统。点击父目录会展开子目录，进入对应页面后当前项会高亮。
- 写作页右侧“操作暂存区”可以完全隐藏；隐藏后中间主编辑区会变宽，右下角按钮可恢复显示。
- 设置中心“主题与背景”中，页面背景、卡片背景、玻璃边框、主文字、次文字、强调色、导航背景、首页面板背景等 token 使用中文名称展示，同时保留内部 token 键。颜色可用颜色选择器或文本框输入。
- 本地资源上传保留 URL 输入方式，同时支持上传图片、音乐和视频到后端本地上传目录，上传成功后自动回填 URL。非法类型或超大文件会被后端拒绝并在 UI 显示错误。
- 前台首页导航已移除“后台入口”；后台仍通过 `http://127.0.0.1:5174/admin/` 或生产后台路径访问。

本手册面向日常使用，不覆盖开发改造。默认本地地址：

- 前台：`http://127.0.0.1:5173`
- 后台：`http://127.0.0.1:5174/admin/`
- 后端 API 文档：`http://127.0.0.1:8000/docs`

生产环境必须先修改 `ADMIN_PASSWORD` 和 `JWT_SECRET`，并设置正确的 `PUBLIC_BASE_URL`。

## 登录后台

1. 打开 `/admin/`。
2. 输入管理员账号和密码。
3. 登录失效或权限不足时，页面会显示可读错误；重新登录后再操作。

本地开发默认账号是 `admin / change-me`，只允许本地演示使用。

## 新建文章

1. 进入 `/admin/editor` 或在 `/admin/posts` 点击“新建”。
2. 填写标题、slug、日期、标签、摘要和 Markdown 正文。
3. slug 会进入公开 URL，只允许字母、数字、下划线和连字符，例如 `vue-fastapi-blog`。
4. 选择草稿状态后点击“保存”，文章会写入 `backend/data/posts`。

## 保存草稿

1. 勾选草稿状态。
2. 点击“保存”。
3. 草稿在后台文章列表可见，但不会出现在前台 `/posts`，公开详情也不可访问。

## 发布文章

1. 在写作页取消草稿并保存，或点击“立即发布”。
2. 在文章管理页也可以对草稿点击“发布”。
3. 发布后前台 `/posts` 会显示该文章，`/posts/{slug}` 可以打开详情。

## 编辑文章

1. 进入 `/admin/posts`。
2. 点击目标文章的“编辑”。
3. 修改内容后保存。
4. 刷新前台文章详情即可看到最新内容。

## 删除文章

1. 在 `/admin/posts` 点击“立即删除”。
2. 删除前必须确认。
3. 删除会先在 `backend/data/posts/.backups` 生成备份，再移除文章文件。
4. 删除后前台列表不再显示，详情返回 404 或内容不存在。

## 暂存队列

第一阶段 pendingOperations 是后台前端本地队列，刷新页面会丢失。覆盖范围：

- 文章新建
- 文章编辑
- 文章删除
- 草稿发布
- 非 Secret 设置修改

点击“加入暂存”不会立刻写后端。需要在右侧“操作暂存区”点击“应用”或“一键应用全部”，才会调用真实后端 API 写入。图片上传、Secret 修改、评论管理不进入本地暂存队列。

## 管理评论

1. 进入 `/admin/comments`。
2. 页面默认展示有评论的内容索引，不需要手动输入 slug。
3. 点击某篇内容后查看评论列表。
4. 删除评论前会确认，删除会直接写回后端评论 JSON，并在覆盖前生成备份。
5. 删除后刷新前台文章详情，评论应消失。

## 管理友链、项目、音乐、照片

后台入口：

- 友链：`/admin/friends`
- 项目：`/admin/projects`
- 音乐：`/admin/music`
- 照片：`/admin/photos`

每个页面都以表单化管理为主，支持新增、编辑、删除。高级 JSON 编辑只是兜底，不作为主流程。保存后刷新前台对应页面确认同步：

- `/friends`
- `/projects`
- `/music`
- `/photowall`

照片管理可以调用上传接口，上传成功后将 URL 填入图片记录。

## 修改站点设置

进入 `/admin/settings`，按分区修改：

- 站点公开信息
- 主题与背景
- 评论设置
- 图床设置
- AI 设置
- 部署与安全提示

公开设置会进入前台。AI Key、OSS Key、GitHub OAuth Secret 等私有配置只保存在后端，后台只显示 configured 状态，不回显明文。Secret 输入框留空保存会保留旧值。

主题与背景分区支持昼夜模式视觉 token：

- 字体族：留空使用默认字体，也可以填写 CSS 字体栈。
- 字号档位：小 / 中 / 大。
- 日间模式 token：页面背景、卡片背景、边框、文字主色/副色、强调色、顶部导航和首页模块颜色。
- 夜间模式 token：同上，用于夜间主题。

前台首页的“日间模式 / 夜间模式”卡片会切换当前浏览器本地偏好；刷新后仍保留。后台保存的 token 会进入 `/api/settings/public`，前台刷新后生效。不要在主题 token 中填写任何 Secret。

关闭评论后，前台文章详情显示“评论已关闭”，不显示提交框。重新开启后评论框恢复。

## 创建备份

1. 进入 `/admin/backups`。
2. 点击“创建手动备份”。
3. 备份写入 `backend/data/.manual_backups/{timestamp}.zip`。
4. 备份 zip 不包含 `.env`，`settings.json` 中的 Secret 字段会被清洗。

建议在升级、恢复、导入或迁移前创建并下载备份。

## 恢复备份

1. 进入 `/admin/backups`。
2. 选择备份，点击“恢复”。
3. 二次确认后执行。
4. 恢复会覆盖当前 `backend/data`，系统会先创建 `pre-restore-*.zip` 恢复前备份。
5. 恢复后检查前台、后台、上传文件和 RSS/Sitemap。

## 查看审计日志

进入 `/admin/audit` 查看操作记录。审计日志覆盖登录、文章变更、评论删除、设置修改、上传、备份、恢复、导入导出等高风险操作。

审计日志不应包含 Secret 明文。

## 前台内容发现

- 搜索：`/search`
- 标签：`/tags` 和 `/tags/{tag}`
- 归档：`/archive`

搜索支持关键词、类型和标签筛选。归档按年月聚合公开文章、动态和杂谈。草稿不会出现在公开搜索、标签或归档中。

## RSS、Sitemap、Robots

本地地址：

- RSS：`http://127.0.0.1:8000/api/rss.xml`
- Sitemap：`http://127.0.0.1:8000/api/sitemap.xml`
- Robots：`http://127.0.0.1:8000/robots.txt`

生产环境请设置 `PUBLIC_BASE_URL`，用于生成 RSS、Sitemap、robots、OpenGraph 和上传 URL。

## 常见问题

- `npm run dev` 是常驻命令，不会自然退出。
- 前台固定 5173，后台固定 5174，后端固定 8000；端口被占用时先释放端口，不要让 Vite 自动跳端口。
- 前台看不到文章时，先确认文章不是 `draft=true`。
- 评论提交失败时，检查评论开关、邮箱要求、最大长度和后端错误提示。
- 上传失败时，检查文件类型、MIME 和大小限制。
- 生产部署前必须修改默认管理员密码和 JWT Secret，收紧 CORS，并先创建数据备份。
- 真实服务器、域名和 HTTPS 实操仍按 `docs/DEPLOYMENT.md` 与 `docs/PRODUCTION_CHECKLIST.md` 执行。
# 2026-05-03 使用补充：前台评论入口与列表页改版

- GitHub 评论登录入口位于前台文章详情评论区；后台只负责配置 OAuth，不作为访客登录入口。登录成功后应返回原文章详情继续评论。
- 未配置 GitHub OAuth 时，前台文章详情显示“GitHub 登录未配置，请联系站点管理员”；未登录时不显示评论输入框，只显示 GitHub 登录按钮。
- 文章列表和杂谈列表使用统一的三列图片卡片布局；大屏每行三篇，小屏自动降列。
- 除首页外，主要页面标题和副标题默认居中，正文区域仍按各页面内容保持可读布局。
- `/music` 页面左侧是播放器，右侧可在“歌词 / 歌单”之间切换；首页和音乐页共享同一播放状态。
