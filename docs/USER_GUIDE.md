# SRBlogs 真实使用手册
## 2026-05-09 后台管理台使用说明

后台主导航已收敛为“内容管理、设置、审计日志、备份恢复”。旧入口保留兼容跳转，但日常管理建议从这四类入口进入。

内容管理：

- 文章：通过“正经 / 杂谈”开关切换文章类型。新增和编辑会进入 Markdown 写作页，支持导入 `.md` 文件、上传正文图片并插入 Markdown、设置封面图和单独维护卡片简介。简介会显示字数，便于控制前台卡片展示长度。
- 图片：按相册组管理，不再按单张图片作为主流程。每个相册最多 50 张图片，可批量上传、删除、排序，并选择封面；未指定封面时默认使用第一张。
- 音乐：管理歌曲列表，支持上传音频文件和歌词文件，歌词优先使用 `.lrc`，也兼容 `.txt`。
- 项目和友链：以卡片数据管理，必须维护跳转链接；封面为空时使用站点默认封面。
- 关于：维护前台关于页的主要结构化文案，保留 Markdown 内容编辑能力。
- 留言管理：文章、图片、音乐等留言在内容项下按目标页面管理，支持查看、删除、刷新和开关对应留言区。

设置：

- 站点信息设置：维护站点标题、副标题。
- 我的信息设置：维护首页名片与关于页联系方式，包括名称、简介、GitHub、Email、QQ、微信。
- 主题设置：维护点击音效、鼠标点击特效、音效音量、音效 URL 和日/夜壁纸组。
- 留言设置：维护 GitHub/QQ OAuth 留言登录配置。Secret 留空保存时保持旧值，不会回显明文。

## 2026-05-07 壁纸轮播说明

前台背景继续使用壁纸轮播。后台主题的日间/夜间壁纸组可以分别配置；如果当前主题没有配置对应模式的壁纸，前台会自动回退到旧版全站背景图列表。游客工具箱中的“背景”和“背景轮播”会作用于当前有效壁纸列表，背景切换带淡入淡出动画。

后台“主题设置”里的白天模式壁纸和夜晚模式壁纸现在可以分别设置是否轮播、轮播间隔和切换动画。白天模式不再叠加背景蒙层，壁纸会直接作为页面氛围层显示；夜晚模式仍可使用黑色蒙层提升文字可读性。切换昼夜模式时，前台会立即触发一次壁纸切换动画。

## 2026-05-06 前台阅读与音乐页说明

前台白天模式的普通页面文字统一使用深色主题文字，夜间模式使用浅色主题文字。文章页、图片页、音乐页、项目页、友链页、关于页和搜索弹窗都遵循这一规则；带图片背景的卡片会根据图片明暗自动选择黑字或白字。

文章页内的“正经 / 杂谈”和“矩阵网格 / 中枢链路”是统一分段按钮，当前选中项使用红色重点色。音乐页的“歌词 / 歌单”也使用同一交互规则。

音乐页保持固定结构：上方标题区，主体为左侧播放器与右侧歌词/歌单面板，下方为留言板。播放器继续支持播放模式、音量、进度拖动、喜欢数和歌词同步。

## 2026-05-05 内容宽度、背景轮播与音量控件

前台主内容现在以 `1100px` 为桌面端最大宽度基准。2026-05-06 起，页面布局已回归代码固定实现，后台不再提供组件宽度、高度、跨行、排序、添加或删除等低代码布局能力。后台“页面信息编辑”只维护首页作者、头像、简介、社交链接、页面标题/副标题和关于 Markdown 等真实字段。

历史 `pageLayouts` 字段仅作为 legacy compatibility 保留，前台不再使用它控制首页、文章、图片、音乐、项目、友链、关于布局。主题包也不再承载页面布局，新导出的主题 JSON 不包含 `pageLayouts`。

左下角工具箱的“设置”里可以控制游客本地背景轮播开关；后台“主题与背景”里有站点级“开启前台背景图轮播”开关。站点关闭时，游客不能强制开启。背景图切换会使用淡入淡出动画。

首页和音乐页播放器的音量按钮 hover 后会弹出一个独立的垂直音量滑杆。滑杆可点击和拖动，拖动会立即改变全局音乐音量，并继续和游客设置里的音乐音量保持同步。

## 2026-05-05 内容宽度使用说明

前台桌面端主体内容以 `1100px` 为最大宽度基准。页面编辑器中的组件宽度按 12 栅格计算，`w=12` 约等于 `1100px`，`w=6` 约等于半宽，`w=4` 约等于三分之一宽。

后台不再提供“页面边距设置”作为主流程入口；前台主内容宽度由 1100px 内容框和 12 栅格控制。

旧主题包中的 `pagePadding` 仅作为兼容字段保留，不再建议通过它控制主内容宽度。真正决定组件最大宽度的是 `1100px` 内容框和 12 栅格。

页面编辑中的首页模块尺寸仍由组件自己的 `w/h/rowSpan` 控制。页面边距和组件布局是两套配置，互不覆盖。

## 2026-05-05 主题、边距与背景组管理

在后台“后台设置 > 主题与背景”中可以管理前台主题：

- 背景轮播设置：后台控制站点级开关，游客工具箱控制本地偏好。
- 主题新建：可以基于当前主题或默认红白黑玻璃主题创建新主题。
- 主题编辑：可以修改主题名称、描述、作者、日间/夜间配色、日间/夜间背景壁纸组。
- 主题删除：只能删除非当前启用主题；当前主题需要先切换后再删除。
- 主题导入/导出：导出的 JSON 只包含公开视觉和布局配置，不包含任何 Secret。

日间模式和夜间模式可以使用不同背景壁纸组。切换昼夜模式时，前台会读取当前主题对应模式的背景组和蒙层配置。

播放器使用说明：

- 首页和音乐页的进度条支持点击跳转和拖动。
- 音量按钮 hover 后显示垂直音量条，鼠标离开约 0.5 秒后隐藏；拖动时不会自动关闭。
- 喜欢按钮旁显示当前歌曲喜欢数，喜欢数会同步到音乐页歌单排序。

## 2026-05-04 页面布局与透明度设置

后台“页面编辑 > 首页”会读取 `/api/admin/pages/config`。调整 8 个首页组件的顺序、宽度或高度后，点击保存会写入 `backend/data/page_config.json`；前台首页刷新时通过 `/api/pages/config` 读取并应用。恢复默认布局同样会写回默认配置。

后台“设置中心 > 主题与背景 > 前台透明度设置”可以调整工具箱设置弹窗、全局搜索弹窗、计算器弹窗、首页卡片、首页轮播、文章/杂谈卡片、图片卡片、音乐卡片、留言板和顶部导航栏的不透明度。透明度设置是公开视觉配置，不包含 Secret。

工具箱悬浮球和菜单项属于可交互元素，点击音效会跟随游客设置和后台站点级开关生效；点击空白区域不会播放音效。

## 2026-05-03 首页页面编辑器硬修复说明

后台进入“页面编辑 > 首页”后，当前首页不再作为一整块假预览处理，而是拆分为 8 个真实前台模块：

- 名片：`profileCard`
- 音乐播放器：`musicPlayer`
- 歌词区：`lyrics`
- 最新文章轮播：`latestPostsCarousel`
- 图片轮播：`photoCarousel`
- 更新内容轮播：`updatesCarousel`
- 昼夜切换：`themeToggle`
- 底部状态区：`statusBar`

每个模块都可以单独调整顺序、宽度和高度。保存后，后端会写入 `backend/data/page_config.json`，前台首页刷新时通过 `GET /api/pages/config` 读取并应用。恢复默认布局会写回默认配置，前台刷新后同步恢复。

首页作者、头像 URL、首页简介和社交链接的主编辑入口已经迁移到“页面编辑 > 首页”。“后台设置 > 站点公开信息”只保留站点标题、副标题等全站级字段；旧首页资料字段只作为兼容折叠区保留。

游客工具箱中的字体大小只调整文字字号，不会等比例缩放卡片、图片、播放器、弹窗或页面网格。点击视觉特效响应页面任意点击；点击音效只响应按钮、链接、导航项、工具箱菜单项、保存/上传/搜索等可交互元素。

## 2026-05-03 页面编辑器第一阶段

后台左侧进入“页面编辑”后，可以按前台页面选择：首页、文章、图片、音乐、项目、友链、关于。

- 首页：编辑作者、头像 URL、首页简介和社交链接；这些字段会同步到前台首页名片。首页预览区支持拖拽核心模块位置、拖动右下角调整大小，保存后刷新前台首页生效；“恢复首页默认布局”可回到默认配置。
- 文章：编辑文章板块标题/副标题，以及整合在文章页里的杂谈板块标题/副标题。
- 图片、音乐、项目、友链：编辑对应页面标题和副标题，并显示真实数据数量摘要。
- 关于：直接编辑真实 `about.md` Markdown，保存后前台关于页更新。

设置中心的“站点公开信息”现在只保留站点标题、副标题等全站级字段。作者、头像、首页简介、社交链接主流程迁移到“页面编辑 > 首页”，设置中心中的旧字段仅作为兼容折叠区保留。

游客工具箱的“字体大小”会影响前台全站字号；“点击特效”和“点击音效”受后台站点级开关限制。站点关闭后，游客不能通过本地设置重新开启。

## 2026-05-03 前台导航与工具箱使用

当前前台顶部导航为：首页、文章、图片、音乐、项目、友链、关于。搜索、杂谈和归档不再作为顶部导航入口，但旧路由仍保留兼容。

文章页 `/posts` 现在整合两个板块：

- “正经”：展示原文章 posts。
- “杂谈”：展示原杂谈 chatters。

在文章页右上角可以切换“正经 / 杂谈”。两个板块都支持“矩阵网格 / 中枢链路”两种显示模式；URL 会同步为 `/posts?section=posts` 或 `/posts?section=chatters`，便于分享和刷新。

图片页继续使用 `/photowall`，导航中显示为“图片”。图片页支持“矩阵网格 / 中枢链路”两种相册展示模式，点击相册封面仍可查看相册内全部图片和留言板。

左下角工具箱是游客可用的全局入口：

- 计算器：支持基础四则运算、括号、小数、清空和退格。
- 全局搜索：复用站内搜索能力，可按关键词、类型和标签筛选。
- 设置：可调整昼夜模式、主题、背景、氛围、弹幕、点击音效、点击音效音量、音乐音量和字体大小。

这些游客设置优先保存在浏览器 localStorage 中，不需要后台登录，也不会读取或暴露后台 Secret。

## 2026-05-03 工具箱与后台导航使用说明

前台左下角工具箱提供三个入口：

- 计算器：小浮窗形式，不阻塞页面，可用 Esc 关闭。
- 全局搜索：可按关键词、类型和标签搜索站内公开内容。

## 2026-05-04 组件样式 DIY 与音乐喜欢

在后台“后台设置 > 主题与背景”中，可以进入“组件样式 DIY”分组，为主要前台组件分别设置日间/夜间颜色、透明度和大小档位。透明度范围是 `0` 到 `1`：`0` 表示完全透明，组件功能仍存在，但视觉上可能看不到。

第一阶段支持的组件包括顶部导航栏、左下角工具箱、工具箱弹窗、Toast、首页名片、首页音乐播放器、首页歌词区、首页轮播、文章/杂谈/图片卡片、音乐页面板、留言板、搜索框、搜索按钮和标签按钮。保存后刷新前台即可看到效果。

## 2026-05-04 页面编辑精细尺寸与后台平面化说明

在后台进入“页面编辑 > 首页”后，每个首页组件都可以用宽度滑动条、高度滑动条和数字输入框精确调整尺寸。

- 宽度 `w` 范围为 `1-12`，支持 `0.1` 精度。桌面端前台会按 120 个子列应用该宽度。
- 高度 `h` 范围为 `0.5-6`，支持 `0.1` 精度。前台会将该值应用为组件最小高度。
- 修改滑动条或数字输入后，后台预览会立即变化。
- 点击保存后，刷新前台首页即可看到真实布局变化。
- 点击恢复默认布局后，后台数值和前台首页都会回到默认顺序与尺寸。

# 2026-05-05 页面编辑组件设置说明

在后台进入“页面编辑”后，点击任意组件会打开“组件详细设置”弹窗。弹窗按四个分组组织：

### 首页跨行布局

后台 `页面编辑 > 首页` 中的组件布局支持：

- `w`：组件宽度，占 12 栅格中的列数。
- `h`：组件高度系数。
- `rowSpan`：跨行数量，用于让某个组件纵向跨两行。

例如把最新文章轮播设置为 `w=4`、`rowSpan=2`，再把图片轮播设置为 `w=8`，即可形成左侧高卡片、右侧上下分区的首页结构。保存后刷新前台即可看到真实变化。

## 后台版本更新

后台“设置 > 版本更新”会显示当前本地版本，并可手动检查 `ShrinkShi/SRBlogs` 的 GitHub Releases。发现新版本后，可以选择“忽略此版本”或“一键更新”。

一键更新默认关闭。服务器管理员需要在后端环境变量中设置：

```env
SRBLOGS_UPDATE_ENABLED=true
SRBLOGS_UPDATE_COMMAND=你的部署更新脚本
```

后台页面不会保存或发送更新命令；命令只从后端环境变量读取。建议把实际更新流程封装成可回滚的脚本，例如拉取代码、安装依赖、构建、迁移和重启服务。
